# Samples

Ports of the classic [XSLTForms](https://github.com/AlainCouthures/xsltforms)
`testsuite/samples` forms (and a few extra that exercise groups, repeats,
and switch). The XSLTForms `xml-stylesheet` processing instruction is
omitted: XFormsKit interprets the XHTML+XForms host document directly.

Open any `.xhtml` file with **XFormsViewer**.
